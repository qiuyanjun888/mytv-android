# 电视盒子 ADB 唤醒与调试启动设计

**目标**

将应用默认 IPTV 源改为 `http://192.168.8.8:9000/iptv/sh/test.m3u`，并通过 ADB 连接电视盒子 `192.168.8.150`，在必要时尝试唤醒设备，随后安装、清理应用数据并启动应用进入调试状态。

**范围**

- 修改默认 IPTV 源常量。
- 构建并安装调试包到目标盒子。
- 通过 ADB 发送唤醒与返回桌面相关按键。
- 为保证默认源生效，清理应用数据后再启动应用。

**不在范围内**

- 不修改节目单默认地址。
- 不新增设置迁移逻辑。
- 不为这次一次性调试增加新的 UI 或命令入口。

**方案**

1. 直接修改 `Constants.IPTV_SOURCE_URL`。
2. 构建 `debug` APK。
3. 使用 ADB 连接 `192.168.8.150`。
4. 向设备发送 `KEYCODE_WAKEUP`、`MENU`、`HOME`，尽量从睡眠或屏保页恢复到可交互状态。
5. 安装最新 `debug` 包。
6. 执行 `pm clear top.yogiczy.mytv`，确保应用重新回退到新的默认 IPTV 地址。
7. 启动 `top.yogiczy.mytv.activities.LeanbackActivity` 并检查前台 Activity 与安装状态。

**风险**

- 如果盒子进入深度待机，`adbd` 可能不在线，ADB 无法完成唤醒。
- 如果局域网或 `192.168.8.8:9000` 不可达，应用启动后可能无法拉取直播源。
- 当前工作区已有未提交改动，构建若失败需要区分是否由现有改动引起。

**验证**

- 本地构建 `assembleDebug` 成功。
- ADB 成功连接到目标设备。
- 应用安装成功。
- 清数据后成功启动 `LeanbackActivity`。
